# CS2 INSIDER – Tudo sobre o cenário competitivo

Blog informativo sobre o cenário competitivo de **Counter-Strike 2**, desenvolvido como atividade acadêmica com HTML5, CSS3 e JavaScript puro (sem dependências).

## Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Home: apresentação, destaques, notícias e curiosidades |
| `campeonatos.html` | Majors, IEM, ESL Pro League, BLAST, calendário e próximos confrontos |
| `times.html` | Organizações profissionais (FURIA, NAVI, Vitality, FaZe, G2, Spirit, MOUZ) |
| `jogadores.html` | Jogadores e principais funções do jogo |
| `contatos.html` | Formulário de contato demonstrativo e redes sociais fictícias |

## Estrutura

```text
cs2-insider/
├── index.html
├── campeonatos.html
├── times.html
├── jogadores.html
├── contatos.html
├── css/style.css
├── js/script.js
└── img/
```

## Como executar

Abra o arquivo `index.html` diretamente no navegador. Não é necessário instalar nada.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub e envie **os arquivos desta pasta** (o `index.html` precisa ficar na raiz do repositório).
2. No repositório, abra **Settings > Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde alguns minutos. O site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Observações

- O formulário de contato é **demonstrativo**: não há backend e nenhuma mensagem é enviada.
- O calendário e os "Próximos confrontos" usam **datas fictícias** (2099), claramente identificadas.
- As imagens são **ilustrações originais**; não são logotipos oficiais nem fotografias dos jogadores.
- Elencos e equipes atuais mudam com frequência e não são apresentados como confirmados.
- Counter-Strike é marca da Valve Corporation. Este projeto não é afiliado à Valve nem às organizações citadas.
